# WebPart1

Consists of 6 pages: HOME, ABOUT, CONTACT, ENQUIRIES, POLICY, BLOG. It is a Non-profit Organization with the sole purpose telling stories, open for donations and caring for people who need Feminine hygiene products.

## Navigation

The Logo.png takes you back to the homepage, there are different tabs for subcategories serving a different purpose within the website. Homepage has introduction that leads to a button which brings in the audience to start searching for more. It briefly explains the services we provide and payment methods available for all to donate. Another navigation point is the open text box for users to enter their email address when they are interested in updates for the website. And below we brief our 'About Us' to conclude.
